# Músicas e letras da playlist "Kauan e Gabi"

Coloque nesta pasta (pelo GitHub: **Add file › Upload files**):

| Arquivo | O que é |
|---|---|
| `imprevisto.mp3` (ou `.mpeg`) | Áudio de "Imprevisto" — Yago Oproprio |
| `enigma.mp3` (ou `.mpeg`) | Áudio de "Enigma" — Yago Oproprio |
| `imprevisto.lrc` ou `imprevisto.json` | Letra sincronizada de "Imprevisto" |
| `enigma.lrc` ou `enigma.json` | Letra sincronizada de "Enigma" |

Os nomes precisam ser exatamente esses (minúsculas, sem acento).

## Como o jogo usa
- Com os áudios aqui, a playlist toca **automaticamente o jogo inteiro**, a partir do toque em "Começar",
  sem parar entre os capítulos e alternando as duas faixas.
- No capítulo do carro aparece o player com a letra sincronizada (frase atual em destaque).
- Sem os áudios, o jogo usa a trilha instrumental original.

## Formato da letra
**LRC** (texto simples, um tempo por frase):
```
[00:12.40] primeira frase
[00:15.10] segunda frase
```
Ou **JSON**, gerado pelo botão "Copiar dados para publicar" em Menu › Músicas e letras, depois de sincronizar no próprio jogo.

Cada novo commit nesta pasta publica automaticamente no Railway.
